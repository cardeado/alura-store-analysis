# Análise de Vendas da Alura Store

## Objetivo da Análise

O objetivo deste projeto é analisar o desempenho de 4 lojas da Alura Store com base em métricas como faturamento, 
categorias mais populares, avaliações dos clientes, produtos mais e menos vendidos e custo de frete.
 A análise visa identificar a loja com menor desempenho para recomendar a sua venda.

## Estrutura do Projeto

- **AluraStoreBr.ipynb**: Notebook contendo o código de análise de dados e gráficos.
- **README.md**: Este arquivo com a descrição do projeto e instruções de uso.

## Exemplos de Gráficos e Insights Obtidos

- **Faturamento por Loja**: Gráfico de barras comparando o faturamento total das lojas. A Loja 1 tem o maior faturamento.
  
- **Categorias Mais Populares**: Gráfico de pizza mostrando as categorias de produtos mais vendidos. Móveis e eletrônicos são as mais populares.
  
- **Média de Avaliações**: Gráfico de barras comparando a média de avaliações das lojas. As lojas 2 e 3 possuem melhores avaliações.

## Instruções para Executar o Notebook

1. Abra o notebook no [Google Colab].
2. Execute as células para visualizar os resultados e gráficos.
3. Verifique se os dados das lojas estão corretamente importados.
